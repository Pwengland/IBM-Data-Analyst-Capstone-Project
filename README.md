# IBM-Data-Analyst-Capstone-Project

## Project Overview
This project was completed as part of the IBM Data Analyst Professional Certificate using data from the 2024 Stack Overflow Developer Survey.

The objective was to investigate demographics, remote work preferences, technologies, and professional experiences of respondents through data analysis and visualisation.

The project involved data wrangling, exploratory data analysis, statistical analysis, and data visualisation, with the aim of drawing meaningful insights from the survey data.

## Data
2024 Stack Overflow Developer Survey - 
[Download the original survey dataset(.csv)](https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/VYPrOu0Vs3I0hKLLjiPGrA/survey-data-with-duplicate.csv)

## Objectives
The main objectives of this project were to:
- Investigate the demographics of survey respondents
- Identify the most popular and most desired programming languages
- Examine remote work preferences
- Explore the relationship between professional experience and job satisfaction
- Investigate annual compensation and how it varies across countries

## Project Workflow

5. Presentation of findings

## Key Findings
- JavaScript was the top programming language among respondents
- Hybrid work was the most common working situation, though this varied in different countries
- Professional experience was not found to be a reliable predictor of job satisfaction
- Software development was the top industry among respondents
- The USA was found to provide the highest mean annual compensation
